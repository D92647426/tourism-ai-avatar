# 游客体验视觉约定

Mode: Operate。基于既有观察界面扩展，非品牌重设计；没有批准的效果图，代码与实际截图验收。

THESIS: 从“看导游说话”推进到“游客编排、观察、提问”的主动使用流程。
OWN-WORLD: 继承绿墨、纸白、细分隔、中文衬线标题与系统正文；后台保持原样。
STORY: 顶栏导航 → 条件编排 → 可解释站点 → 自己的观察 → 景点检索与数字人问答。
FIRST VIEWPORT: 能识别产品，并看见可操作的编排表单和情境按钮，不用装饰性统计承诺价值。
FORM: 行程和景点采用横向编辑行，观察区保留任务目录和写作台；手机为自然单列，缩短导航。

扩展范围不新增品牌、图片世界或独立设计系统。已有来源边界、导游模型和展示配置功能保留。必须保持长中文、错误/空态、焦点与手机无溢出；手册记录不以装饰进度替代真实发现。
