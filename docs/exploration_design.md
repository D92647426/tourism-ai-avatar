# REQ-032：今天你当导游

用户授权继续发挥开源课设创意。本轮由 Codex 选择“观察 → 反向讲解 → 资料对照 → 旅程手册”的可体验首版；不代表三位组员已经共同投票，也不承诺课程分数。

## 体验与验收

1. 首页有独立的田野笔记区域，默认“课堂演示”，也可选择“现场观察”。三个示例站点：灵山大佛、九龙灌浴、灵山梵宫；可自由选站，不伪造 GPS 到访或路线距离。
2. 每站显示一个可亲自观察的问题与可展开提示，输入自己的讲解。4–1200 字记录，每站只保留最新一条，修改不重复计数。
3. 保存后分开显示“我的观察”“资料线索”“关键词对照”。关键词出现只能说明提及了该词，不能判定事实正确、理解程度或得分。不依赖模型 Key。
4. 来源与待核对状态始终可见。继承资料明确标作“老师项目资料，待实地或官方核对”，个人观察不进入公共知识库。
5. “带着发现问导游”经现有聊天入口显式发送，附本次景点、任务和个人观察。先展示可编辑草稿，不覆盖聊天框中已有草稿，不自动发送；忙时明确提示。不能声称已有服务端长期记忆。
6. 本机按登录用户隔离保存内容包、当前站和记录。刷新恢复；JSON 损坏、存储被禁用或空间不足时可继续临时体验并提示未保存。跨版本记录不混入新内容包。
7. 内容包可下载 JSON，导入本机 JSON 后预览标题、作者、站点数、素材说明，用户明确点击使用才替换。失败保持原旅程；切包前说明原包旅程仍按包保存，重新导入原包可恢复。文件最大 128 KiB、最多 12 站，限制字段长度、唯一 ID 与安全来源链接；不执行包中的 HTML/脚本。
8. 可下载 Markdown 旅程手册，明确区分课堂演示/现场个人记录、自己的话与资料线索，只包含实际记录及其来源，不生成假到访。无记录时下载按钮禁用。
9. 提供第二份原创的“校园观察”演示包，课堂导入即可换场景，无需改 Java 代码。原始资料许可没有确认前，不宣称取得额外授权。

## 界面决定

布局：一段简短邀请、左侧站点目录、右侧当前任务与书写区；下方是已记录的发现和内容包工具。移动端先目录再当前任务，保留现有景点浏览与数字人。

色彩：墨绿 #16352f、湖绿 #11665b、浅青 #f0f7f4、白 #ffffff、嫩叶 #c9dfba、提示棕 #9c6b24。标题使用本机宋体/衬线，操作文字沿用现有中文无衬线。序号只表示实际站点顺序，不装饰统计卡。新样式限定在 exploration 区域；尊重 reduced-motion。

## 模块接口与限制

纯规则模块 `GuideExploration` 提供 validatePack/createJournal/restore/record/compare/buildPrompt/exportMarkdown，不依赖 DOM、fetch 或存储。页面模块负责安全 DOM、文件导入、存储和下载；主聊天模块只增加一处受保护的草稿交接事件。

内容包 schemaVersion=1，id/version/title/author/licenseNotice/tasks；每站 id/spotName/title/prompt/hint/reference/source(title,url,status)/cues(label,terms)。source.status 仅 inherited-unverified 或 original-demo，url 仅 https。示例源链接定位到仓库继承文件，不冒充实时官方资讯。任务顺序是内容目录，不是经校验的游览导航。

存储边界：`tourism-explore:v1:<userId>` 保存当前包与选中站；`tourism-journal:v1:<userId>:<packId>:<version>` 保存该包记录。版本用于隔离，不能跨包误用旧记录。所有数据仅在本机，尚无跨设备同步或端到端加密承诺。

范围不含后端会话、评分、GPS、排行榜、训练模型或实时开放时间。继承基线见 [UPSTREAM.md:L1](../UPSTREAM.md#L1)。本轮从聊天改进分支叠加，PR 以该分支为基准，认证 PR 仍独立。

## 验证计划

规则测试覆盖字段/长度/ID/URL校验、失败无修改、记录替换与统计、跨包/跨版本恢复隔离、恶意字符串安全导出、关键词不判对错、提示词来源与模式、只导出实际记录。页面测试检查存储异常、导入确认、草稿保护与忙态交接。完成后执行现有测试、Maven、文档链接和隔离 HTTP 检查；能运行浏览器时验证桌面与窄屏并截图。

## 体验修正

桌面/窄屏实测后缩小窄屏浮动角色并适配窗口变化，避免大面积遮住讲解文字；聊天框改为多行，保留带入草稿的换行。新增资源使用 explore-1 查询版本以避免旧静态缓存；以后变更这些资源时同步增加该版本。资料来源始终可见，正文线索可折叠。存储失败时按包保留当前页内存记录，仍提示刷新可能丢失。
