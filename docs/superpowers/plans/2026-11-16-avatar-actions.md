# 燕小北全身动作与情境表情实施计划

REQ-065沿用三套v8衣装，增加学习、用餐、思考、馋嘴、庆祝和疑惑六类动作。学习与用餐采用自然三分之四侧身，其他姿态结合侧头与重心变化。

## 动效方案

核心呈现为用户提到学习或食堂后，燕小北自然换成有书桌、课本、电脑或餐碗的动作。输入、回复和主场景共同驱动状态，保留手动预览。全身跟随包含侧身、重心、呼吸、发丝和后翼，学习时桌面保持稳定。

动作准备完成后再切换，使用短淡入，连续操作以最后请求为准。真实声音仍驱动口型，语音停止与静音边界关闭播报口型。页面隐藏或角色离屏暂停，减少动态效果保留姿态和状态提示。

只同时保留当前模型和正在准备的模型，图片、网格和脚本随JAR本地提供。动作资料参考本机dsh-pet 0.3.8的动作与事件分类。
