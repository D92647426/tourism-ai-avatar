# 燕小北 v8 与形象切换实施计划

对应 REQ-064，依据本轮用户确认的 v7 造型与细腿、小鞋调整要求。

## 目标与实现

将三套 v8 透明立绘绑定到现有 RuiC-2D 渲染器。校园助手右上角提供形象选择，成功切换后在本机保存衣装偏好。语音控制器持续持有同一个角色接口，切换期间保留已有对话、场景及播放状态。

## 任务

- [x] 使用内置 ImageGen 调整三套衣装，保存透明原图及提示词。
- [x] 生成眼睛和口型差分，记录新立绘坐标，构建三套运行模型。
- [x] 扩展角色控制器的 setAppearance(id)，加载新模型后提交，处理连续切换、失败和离页释放。
- [x] 实现可关闭的形象选择面板，支持键盘与手机触点，成功后记忆选择。
- [x] 通过正常入口测试切换、刷新恢复、声音联动、资源失败及减少动态效果。
- [x] 更新形象、需求、程序、配置与测试记录，重新打包并在网页查看。

## 验收重点

三套新造型的腿和鞋明显收小，脸、下巴、呆毛及后翼延续 v7。快速切换时最后一次选择生效，失败后现有人物仍可用。刷新后恢复成功选择。静音和停止声音均闭口，正在播报时换装继续正确响应。模型失败可显示同衣装静态立绘。桌面和手机面板均可关闭，图片和文字不溢出。

实际验证与剩余业务缺口见[本轮复查](../../campus_review_2026-11-16.md#L1)。
