# 创意方向与当前首版

此前讨论的候选继续保留，供三人选择：

1. 今天你当导游：游客通过观察和解释教会数字人，旅程记忆影响后续互动。
2. 双人拼图游：同行者分别持有线索，协作完成景区观察任务。
3. 同景异时：同一景点切换不同年代或角色的叙事视角，并对照资料。
4. 全队路线协商：综合同行者兴趣和行动限制，解释路线取舍。
5. 景区内容包：将景点、观察任务、知识依据、提示和角色台词制作成可复用内容。

导入基线时尚未实现上述创意。之后的实现和选型见下列日期记录；Issue #1 的小组共同确认仍待完成。
