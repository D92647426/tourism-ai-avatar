# 项目议题来源

按用户已选平台，使用 GitHub [tourism-ai-avatar Issues](https://github.com/D92647426/tourism-ai-avatar/issues)。已有议题正文包含范围、依赖与验收，实施时先核对当前状态及认领。依赖未合并时可在对应分支上建立堆叠PR，说明合并顺序；不把其他任务一并引入。

每项工作独立 `codex/` 分支，提交关联议题的PR并等待组员评审；不自动合并或提前关闭议题。约定见 [CONTRIBUTING.md:L21](../../CONTRIBUTING.md#L21)。本次未启用额外外部PR分流或更改标签状态机。
